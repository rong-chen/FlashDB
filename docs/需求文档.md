# FlashDB 数据库管理工具需求规格说明书

## 一、项目定位

| 项目 | 说明 |
|------|------|
| **名称** | FlashDB |
| **类型** | 跨平台桌面客户端 (GUI) |
| **核心价值** | 轻量级、无 AI 纯粹工具、高性能 SQL 执行、自动化 Schema 对比 |
| **技术路线** | Wails (Go 后端) + Vue 3 (前端 UI) |

---

## 二、核心需求 (P0：基础生存阶段)

> **目标**：实现从连接到查询的完整闭环，替代基础命令行操作。

### 2.1 连接管理 (Connection Manager)

| 功能项 | 详细说明 |
|--------|----------|
| **驱动支持** | 首发支持 MySQL 8.0+ 及 PostgreSQL 12+ |
| **配置项** | 主机(Host)、端口(Port)、用户名、密码、初始数据库 |
| **SSH 隧道** | 支持 SSH 代理连接（用户名、密码/私钥认证），解决内网穿透需求 |
| **环境标记** | 支持为连接设置颜色（如：Red-生产, Green-开发），界面边框或标题随颜色变化 |
| **连接存储** | 本地 SQLite 存储配置，密码需进行 AES-256 加密 |

### 2.2 对象浏览器 (Object Explorer)

| 功能项 | 详细说明 |
|--------|----------|
| **层级结构** | 实例 → 数据库 → 表 → [列/索引/外键] |
| **快速过滤** | 顶部搜索框，支持对表名进行实时模糊匹配 |
| **右键菜单** | 复制表名、查看 DDL (建表语句)、清空表数据 (TRUNCATE)、删除表 |

### 2.3 SQL 编辑器 (Query Console)

| 功能项 | 详细说明 |
|--------|----------|
| **多页签管理** | 支持同时开启多个查询窗口 |
| **语法增强** | 基础 SQL 语法高亮（Monaco Editor 集成） |
| **执行逻辑** | 支持"执行选中代码"或"执行当前页全部代码" |
| **快捷键** | `Ctrl/Cmd + Enter` 触发执行 |

### 2.4 数据展示网格 (Data Grid)

| 功能项 | 详细说明 |
|--------|----------|
| **虚拟滚动** | 前端渲染必须支持 10 万行级别数据流畅滚动，不卡顿 |
| **基础操作** | 支持字段点击排序、手动调整列宽 |

---

## 三、进阶需求 (P1：效率提升阶段)

> **目标**：通过技术手段解决开发过程中的痛点，拉开与普通工具的差距。

### 3.1 Schema Diff (核心卖点)

| 功能项 | 详细说明 |
|--------|----------|
| **结构对比** | 选择两个已连接的数据库，对比所有表结构 |
| **差异识别** | ① 缺失表识别<br>② 字段类型、长度、默认值、是否为空的差异<br>③ 索引（唯一索引、普通索引）的差异 |
| **脚本导出** | 自动生成最小增量同步 SQL (`ALTER TABLE` 语句) |
| **可视化视图** | 左右对比面板，高亮标出差异行 |

### 3.2 数据编辑与同步

| 功能项 | 详细说明 |
|--------|----------|
| **直接编辑** | 在结果表格双击直接修改数据 |
| **提交机制** | 采用"更改缓冲区"，用户修改多条后，点击"保存"统一生成 SQL 提交 |
| **数据导出** | 支持结果集一键导出为 CSV、JSON、Markdown 格式 |

### 3.3 本地 SQL 工具箱

| 功能项 | 详细说明 |
|--------|----------|
| **SQL 格式化** | 内置格式化引擎，美化杂乱的 SQL 脚本 |
| **执行记录** | 自动记录最近执行成功的 100 条 SQL，支持一键找回 |

---

## 四、高级需求 (P2：深度调优阶段)

> **目标**：面向资深开发人员，提供底层分析能力。

### 4.1 Visual Explain (执行计划可视化)

| 功能项 | 详细说明 |
|--------|----------|
| **图示化渲染** | 将 `EXPLAIN` 的树状结果转化为流程图 |
| **风险预警** | 对"全表扫描 (ALL)"、"Using temporary"、"Using filesort"进行红色高亮预警 |

### 4.2 Smart Mock (测试数据生成)

| 功能项 | 详细说明 |
|--------|----------|
| **规则匹配** | 根据字段类型和字段名（如 `user_name`, `email`, `created_at`）自动生成符合逻辑的伪数据 |
| **批量生成** | 支持指定生成行数（如 1000 条）并快速写入数据库 |

### 4.3 敏感操作审计

| 功能项 | 详细说明 |
|--------|----------|
| **删除保护** | 执行不带 `WHERE` 条件的 `DELETE` 或 `UPDATE` 时，强制弹窗二次确认 |
| **只读模式** | 支持将特定连接设为"ReadOnly"，禁止一切写操作 |

---

## 五、后续扩展需求 (P3：全能演进阶段)

> **目标**：打破单一数据库限制，构建完整的开发生态。

### 5.1 更多引擎适配

| 功能项 | 详细说明 |
|--------|----------|
| **NoSQL 支持** | Redis（键值浏览、TTL 管理）、MongoDB（Document 结构展示） |
| **国产数据库** | 适配 TiDB、OceanBase 等常用国产数据库 |

### 5.2 文档与协作

| 功能项 | 详细说明 |
|--------|----------|
| **数据字典导出** | 一键生成 HTML 或 PDF 格式的表结构说明文档，包含注释信息 |
| **配置同步** | 支持导出加密后的连接配置文件，方便在不同设备间迁移 |

### 5.3 监控面板

| 功能项 | 详细说明 |
|--------|----------|
| **实时状态** | 查看当前数据库的活跃连接数、事务死锁、磁盘占用空间等简单指标 |

---

## 六、非功能性需求

| 类别 | 要求 |
|------|------|
| **性能** | 应用启动时间控制在 2 秒内；内存占用在基础查询下低于 200MB |
| **安全** | 本地配置文件严禁明文存储敏感信息 |
| **UI 风格** | 遵循极简主义，支持系统原生暗黑模式 (Dark Mode) |
| **跨平台** | 一套代码确保在 Windows 10/11、macOS (Intel/M系列)、Linux 下表现一致 |
